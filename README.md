# STERNRITTERS

A luxury bespoke tailoring website concept built with **HTML5 and CSS3 only**.

## Pages

- `index.html` – Home and brand story
- `Suits_Collection.html` – The Atelier, Dynasty and Vesper collections
- `Colours.html` – CSS-only signature shade customiser
- `Size_Ur_Suit.html` – Fit and measurement guide
- `Basket.html` – Suit selection and order-request demonstration
- `contact.html` – Contact and appointment information

## Run locally

Keep the six HTML files, six CSS files and the `images/` folder in the same project directory. Open `index.html` in a browser.

## Technology

- HTML5 for page structure and accessible content
- CSS3 for layout, responsive styling, transitions and the colour selector
- No JavaScript or external image dependencies

## Important demonstration notes

The basket is a front-end demonstration. It does not submit, save or process orders, collect payments, or send customer information. The contact details and social profiles are placeholders and must be replaced before any real-world launch.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the published website address once deployment completes.
